# 주말 제주도 여행 후기

지난 주말에 다녀온 제주도 여행 기록을 남긴다. 금요일 저녁 비행기로 출발해
일요일 밤에 돌아오는 2박 3일 일정이었다.

## 첫째 날

공항에 도착해 렌터카를 빌린 뒤 곧바로 애월 해안도로를 따라 드라이브를 했다.
날씨가 맑아서 바다 색이 정말 예뻤다. 저녁은 흑돼지 구이를 먹었는데
기름이 적당히 올라 고소하고 두툼해서 만족스러웠다.

## 둘째 날

아침 일찍 한라산 성판악 코스를 올랐다. 왕복 8시간 정도 걸렸고 정상에서
백록담을 볼 수 있었다. 내려와서는 근처 카페에서 한라봉 주스를 마시며
피로를 풀었다. 저녁에는 동문시장에 들러 회와 고등어를 사 먹었다.

## 셋째 날

마지막 날은 카멜리아힐 정원을 산책하고 기념품을 샀다. 공항 가는 길에
유명한 국수 거리에 들러 고기국수 한 그릇을 비우고 비행기에 올랐다.

다음에는 우도와 마라도까지 가보고 싶다. 전반적으로 날씨 운이 좋았던
알찬 여행이었다.
